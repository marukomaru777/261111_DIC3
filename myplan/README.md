# A Transportation-Aware Restaurant Recommendation System Using LLM Agents and Semantic Retrieval

**結合大型語言模型代理與語意檢索之交通感知餐廳推薦系統**

本專題以臺中市公車為場域。使用者輸入用餐情境、出發地與時間，以及預算、步行或轉乘限制。系統規劃先從評論召回有情境依據的餐廳，再逐一查核公車方案和用餐時間。交通條件會影響最後的餐廳選擇。每間餐廳保留一條最佳已查核方案，最多推薦三間，並附上評論依據、交通時間線及仍待確認的項目。

**目前進度｜研究提案。** 已有提案正文、簡報、文獻比較、架構圖、流程圖與虛擬案例。評論資料來源確認、TDX 串接、可執行原型與量化評估仍待驗證。本目錄提供研究分析與驗證計畫。

## 研究背景與缺口

提案引用臺中市政府 2025 年的外食分析。2024 年底臺中市有 22,612 家餐飲業營利事業，較 2015 年增加 47.55%。面對大量餐廳選擇，使用者同時需要回答「適不適合這次用餐」和「能不能搭公車準時抵達並完成用餐」。專題聚焦於出發前的臺中公車查詢。（S1，第 7–9 頁。S2，第 2–3 頁。）

文獻涵蓋 AI 技術與領域知識各六篇。TravelPlanner 與形式化規劃研究支持把語言理解和限制查核分工。BRIGHT、混合檢索和 K-RagRec 提供召回與證據組織的方法。餐廳評論研究處理主觀偏好，公車規劃研究則提供班次、轉乘與延誤的分析方法。本提案要驗證的是，讓交通條件在最終選店前參與決策，能否兼顧情境相關性與交通便利性。（S1，第 10–18 頁。S2，第 5–10 頁。）

## 系統設計

1. **整理資料。** 蒐集可使用的評論與店家資料，核對分店、價格和營業時段。向量索引用於召回，圖譜或關聯表保存餐廳、情境屬性和來源片段的關係。
2. **理解需求並召回候選。** LLM 將用餐情境、預算、出發地與時刻整理為固定欄位。影響必要限制的歧義先補問。比較 BM25、向量或混合檢索，按餐廳去重，再排除已知違反靜態限制的候選。
3. **取得交通資料並重建時間線。** 由 TDX 旅運規劃取得候選路線，以公車班表、站位和可用的 N1 到站預估核對服務日、方向、子路線、站位與時間基準。串接步行、候車、乘車、轉乘、抵達和離店。抵達站牌加上緩衝後仍須趕得上班次，完整用餐區間須落在同一段有效營業時間內。
4. **查核與排序。** 每項必要限制記錄 T（通過）、F（已知不符）或 U（證據不足），並保存原因、來源和判定時間。任一 F 排除該路線，有 U 且無 F 則列為暫定，全 T 才依情境相關性與交通負擔評分。每店保留一條最佳已查核路線，最多輸出三間。
5. **說明推薦。** 以判定紀錄產生評論依據、交通比較和未知項。說明無法通過事實查核時，改用固定模板。

設計依據為 S1 第 19–28 頁與 S2 第 9–17 頁。行程中監控、延誤重規劃與回程屬後續擴充。

## 快速案例

簡報第 13 頁的設計示例中，使用者 18:00 出發、18:10 搭上公車、19:00 抵達。若預計用餐 90 分鐘，20:30 才離店，超過 20:00 打烊時間。這條路線的營業條件判為 **F（不通過）**，系統仍會檢查其他路線。若缺少可信班次時間，對應條件判為 **U（不確定）**。只有必要條件全為 **T（通過）** 的組合會進入已查核排序。

## 實驗規劃與預期成果

| 研究問題 | 擬比較的方法 | 觀察指標 |
| --- | --- | --- |
| RQ1 情境召回 | 關鍵字、向量、混合檢索 | 以同一組標註比較餐廳與評論的相關性及召回率 |
| RQ2 交通回饋 | 僅依語意排序、選店後補路線、排序前整合交通 | 情境相關性、步行與候車時間、乘車時間及轉乘次數 |
| RQ3 證據查核 | 在相同資料下比較二值與三值查核 | 必要限制違反率、證據不足仍宣稱可行的比例、已查核推薦覆蓋率 |
| RQ4 完整時間線 | 查詢當下營業或單一 ETA 檢查，對照完整旅程與用餐時間線 | 漏判已錯過班次、無法轉乘及超過打烊的比例 |

比較時固定查詢、資料快照和候選上限。結果應同時呈現錯誤率與覆蓋率，並列出無結果、資料不足與工具失敗的查詢數。預計交付推薦原型、公車方案、評論依據及查核紀錄。減少不可行推薦、維持情境相關性和提升可追溯性都是待驗證的研究假設。（S1，第 8–9、18、28 頁。S2，第 8、18 頁。）

作業規範要求摘要交代動機、缺口、方法、評估與預期成果。現有提案已提供文獻表、領域推理問題、九模組架構、流程圖和編號演算法。既有評讀中的分數屬估計，期末仍須以可執行原型、測試、展示及實驗結果支持交付。（S3，第 1–4 頁。S4，第 1 頁。S5，第 1–3 頁。）
